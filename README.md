# Nanečisto · verejná ukážka

Samostatný statický web s 24 českými prípadmi kariérového poradenstva a 24 českými prípadmi učiteľstva praktického vyučovania. Slovenský jazykový výber obsahuje šesť prípadov pre každý odbor; nejde o preklad všetkých 48 prípadov. České sylaby nie sú slovenským študijným plánom.

Prípady sú autorský nácvik, nie potvrdenie profesnej spôsobilosti. Výsledky zostávajú v prehliadači; stránka automaticky neodosiela výskumné údaje na server.
# Prezentácia systému

Nový prehľad rolí a študentských účtov je na [`studio/`](studio/). Bez pripojeného Firebase projektu obsahuje len výslovne označené ukážkové účty. Postup zapojenia skutočnej databázy a bezpečnostné pravidlá sú v [`studio/README.md`](studio/README.md).
